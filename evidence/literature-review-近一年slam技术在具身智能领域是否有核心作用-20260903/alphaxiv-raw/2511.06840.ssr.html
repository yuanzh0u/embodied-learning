PanoNav: Mapless Zero-Shot Object Navigation with Panoramic Scene Parsing and Dynamic Memory

The Hong Kong University of Science and Technology (Guangzhou)
QJ
Qunchao Jin
YW
Yilin Wu
CC
Changhao Chen

Abstract

Zero-shot object navigation (ZSON) in unseen environments remains a challenging problem for household robots, requiring strong perceptual understanding and decision-making capabilities. While recent methods leverage metric maps and Large Language Models (LLMs), they often depend on depth sensors or prebuilt maps, limiting the spatial reasoning ability of Multimodal Large Language Models (MLLMs). Mapless ZSON approaches have emerged to address this, but they typically make short-sighted decisions, leading to local deadlocks due to a lack of historical context. We propose PanoNav, a fully RGB-only, mapless ZSON framework that integrates a Panoramic Scene Parsing module to unlock the spatial parsing potential of MLLMs from panoramic RGB inputs, and a Memory-guided Decision-Making mechanism enhanced by a Dynamic Bounded Memory Queue to incorporate exploration history and avoid local deadlocks. Experiments on the public navigation benchmark show that PanoNav significantly outperforms representative baselines in both SR and SPL metrics.

AI Overview

Object Goal Navigation (ObjectNav) is a core task in embodied artificial intelligence that requires an agent—typically a robot—to locate and navigate to a specific object within a previously unseen environment. For example, an agent might be told to "find the sofa" in a new house. Success requires the agent to perceive its surroundings, identify potential targets, plan a route, and execute movements, all while understanding the spatial layout of the environment.

Traditionally, this has been approached using map-based methods or reinforcement learning. However, many of these systems rely on specialized depth sensors or pre-existing maps, which may not be available on standard mobile robots. Furthermore, they often struggle with "open-vocabulary" scenarios—tasks where the target object could be anything, not just a category predefined during training. PanoNav is a framework designed to address these challenges by enabling zero-shot object navigation using only RGB visual inputs and a mapless architecture. It integrates panoramic scene parsing with a dynamic memory system to improve exploration efficiency and avoid common navigational pitfalls like local deadlocks.

Figure 1: The PanoNav framework architecture, illustrating the integration of panoramic scene parsing, multimodal large language models (MLLMs), and dynamic memory-guided decision-making.

The Challenge of RGB-Only, Mapless Navigation

Most high-performing ObjectNav systems use RGB-D sensors, which provide both color and depth information. Depth data is crucial for building 2.5D or 3D metric maps that help the robot understand distances and avoid obstacles. When restricted to RGB-only inputs, an agent must infer spatial relationships and distances directly from 2D images, a significantly more complex task.

Additionally, "mapless" navigation means the agent does not build or maintain a persistent geometric map of its environment (like a 2D occupancy grid). Instead, it must make decisions based on its current observation and some form of internal state or memory. Without an explicit map, agents often suffer from "local deadlocks"—situations where the robot becomes trapped in a repetitive loop, visiting the same rooms or corners because it lacks the historical context to know it has already explored those areas. PanoNav is specifically designed to overcome these two hurdles: the lack of depth information and the propensity for local deadlocks.

Panoramic Scene Parsing without Depth Sensors

To perceive the environment effectively without depth sensors, PanoNav utilizes a Panoramic Scene Parsing module. At each timestep ttt, the agent captures a panoramic observation consisting of six RGB images, VitV_i^tVit​, taken at 60-degree intervals. This 360-degree field of view provides more comprehensive context than a standard forward-facing camera.

The framework employs a Multimodal Large Language Model (MLLM) to translate these visual inputs into structured spatial descriptions. To compensate for the lack of depth, the researchers introduce "dot matrix images" (MitM_i^tMit​) generated through Scaffold (SCA) processing. These matrix images provide a planar grid overlay that helps the MLLM reason about the relative positions and distances of objects in the scene.

Figure 2: The process of spatial relationship reasoning where the MLLM combines original RGB images and dot matrix images to construct a latent spatial relation graph (GitG_i^tGit​).

The MLLM performs two levels of parsing:

  1. Local Directional Parsing: For each of the six directions, the model identifies objects, their spatial relationships (e.g., "the chair is behind the table"), the room type, and the likelihood that the target object is located in that direction (ldtld_tldt​).
  2. Global Panoramic Summary: The model generates a holistic semantic overview of the current surroundings, identifying the overall room type (e.g., "kitchen" or "hallway") and listing all visible objects to create a high-level context (gstgs_tgst​).

Addressing Local Deadlocks with Dynamic Memory

A unique contribution of PanoNav is the inclusion of a Dynamic Bounded Memory Queue. In many mapless systems, the agent's decision at any time ttt is based solely on the current observation. This "short-sightedness" leads to redundant exploration.

PanoNav maintains a queue QQQ with a maximum length nnn that stores the global summary descriptions (gstgs_tgst​) from previous timesteps. As the agent moves, new summaries are added and the oldest ones are removed once the queue is full. This historical context is fed into a Large Language Model (LLM) that serves as the central decision-maker.

When making a decision rtr_trt​ (such as "turn left" or "move forward"), the LLM evaluates the current local and global information. If the memory queue is full (ft=1f_t = 1ft​=1), the LLM also considers the history stored in QtQ_tQt​. By "reading" its own history, the agent can recognize if it has been in the current room before and whether that room contained the target. This awareness allows the agent to intentionally move toward unexplored regions, effectively breaking out of potential local deadlocks.

Figure 3: Illustration of the decision-making process. The LLM uses current and historical information to choose a direction that avoids previously explored areas and targets potential object locations.

Performance in Open-Vocabulary Environments

The framework was evaluated on the Habitat-Matterport 3D (HM3D) dataset, a standard benchmark for realistic indoor navigation. PanoNav was tested in a zero-shot setting, meaning it received no specific training on the target objects it was asked to find.

PanoNav achieved a Success Rate (SR) of 43.5% and a Success-weighted Path Length (SPL) of 23.7%. When compared to other RGB-only, mapless, open-vocabulary methods like PixNav and ZSON, PanoNav demonstrated significant improvements. Specifically, it outperformed PixNav by approximately 14.7% in success rate. Interestingly, PanoNav also performed better than several methods that use depth information or build explicit maps, suggesting that the combination of panoramic parsing and LLM-based reasoning is a powerful alternative to traditional geometric mapping.

Figure 4: Sample navigation trajectories in the HM3D dataset. The red lines represent the path taken by the agent to successfully reach target objects like TVs, toilets, and plants.

The Impact of Memory on Exploration Efficiency

To specifically test the ability to escape deadlocks, the researchers designed a "Deadlock Avoidance Test." In this scenario, agents were placed in deceptive locations—such as a living room that does not contain a sofa, even though a sofa is the target. A memoryless agent might circle the room indefinitely, expecting a sofa to appear.

The results showed that agents using the Dynamic Bounded Memory Queue had a success rate of 48.0%, compared to only 12.0% for agents without memory. More importantly, the "Escape Rate"—the ability of the agent to leave a local area and continue searching elsewhere—increased from 32.0% to 82.0% with the addition of memory. This quantitative evidence confirms that keeping a textual history of explored areas is an effective way to manage the exploration-exploitation trade-off in mapless navigation.

Figure 5: Comparison of trajectories with and without memory. Row (a) shows memory-less agents stuck in loops, while row (b) shows PanoNav agents successfully exiting these areas to find the target.

Validating the Framework Components

Ablation studies were conducted to determine which parts of the PanoNav system contributed most to its performance:

  • Panoramic vs. Limited View: Using a full 360-degree view instead of a limited forward-facing view more than doubled the success rate (from 19.5% to 43.5%). This highlights the importance of peripheral awareness in spatial reasoning.
  • Decoupled Perception and Reasoning: The researchers found that using one model (an MLLM) to parse the scene and a separate model (an LLM) to make decisions was more effective than having a single model do both in one step. This decoupling allows the decision-making model to focus on logic and history without being overwhelmed by raw visual data.
  • Memory Contribution: In general navigation tasks, the success rate dropped from 43.5% to 38.5% when memory was removed, confirming its utility even outside of the specific "deceptive" test cases.

Significance and Future Directions

PanoNav demonstrates that sophisticated object navigation is possible without the high hardware costs of depth sensors or the computational complexity of real-time metric mapping. By leveraging the internal knowledge and reasoning capabilities of Large Language Models, the framework shifts the burden of navigation from geometric reconstruction to semantic understanding.

The use of textual memory (the global summary queue) provides a lightweight alternative to traditional maps. This approach is particularly well-suited for robots with limited computational resources or those operating in dynamic environments where static maps quickly become obsolete. Future research may explore expanding the memory capacity further or incorporating other modalities, such as audio or tactile feedback, into the panoramic parsing module. By successfully navigating complex, unseen environments using only standard camera inputs, PanoNav provides a robust path forward for the development of more accessible and versatile autonomous agents.
