Abstract

We present MG-Nav (Memory-Guided Navigation), a dual-scale framework for zero-shot visual navigation that unifies global memory-guided planning with local geometry-enhanced control. At its core is the Sparse Spatial Memory Graph (SMG), a compact, region-centric memory where each node aggregates multi-view keyframe and object semantics, capturing both appearance and spatial structure while preserving viewpoint diversity. At the global level, the agent is localized on SMG and a goal-conditioned node path is planned via an image-to-instance hybrid retrieval, producing a sequence of reachable waypoints for long-horizon guidance. At the local level, a navigation foundation policy executes these waypoints in point-goal mode with obstacle-aware control, and switches to image-goal mode when navigating from the final node towards the visual target. To further enhance viewpoint alignment and goal recognition, we introduce VGGT-adapter, a lightweight geometric module built on the pre-trained VGGT model, which aligns observation and goal features in a shared 3D-aware space. MG-Nav operates global planning and local control at different frequencies, using periodic re-localization to correct errors. Experiments on HM3D Instance-Image-Goal and MP3D Image-Goal benchmarks demonstrate that MG-Nav achieves state-of-the-art zero-shot performance and remains robust under dynamic rearrangements and unseen scene conditions.

AI Overview

Introduction

Visual navigation represents a fundamental capability for embodied artificial intelligence, enabling autonomous agents to navigate complex environments toward visual targets without explicit maps or dense supervision. This paper introduces MG-Nav, a dual-scale framework that addresses critical limitations in current visual navigation approaches by combining sparse spatial memory with geometry-enhanced local control.

Current visual navigation methods fall into three main categories, each with significant drawbacks. Foundation policy models like GNM and ViNT excel at short-horizon control but lack long-range reasoning capabilities due to their memory-free, reactive nature. Reinforcement learning approaches can incorporate sophisticated reasoning but struggle with generalization to unseen environments and require massive training data. Memory-based methods construct persistent global maps for long-horizon planning but rely on computationally expensive and brittle dense 3D reconstructions that fail when environments change.

MG-Nav draws inspiration from human navigation strategies, which effectively combine sparse visual memories for global guidance with continuous local adaptation for immediate obstacles. This bio-inspired approach aims to bridge the gap between robust local control and efficient global planning, addressing the fundamental challenge of achieving generalized navigation in dynamic, real-world environments.

Methodology

The core innovation of MG-Nav lies in its dual-scale architecture that integrates a Sparse Spatial Memory Graph (SMG) for global planning with a geometry-enhanced local navigation policy. This design enables hierarchical reasoning while maintaining computational efficiency and robustness to environmental changes.

Global Planning with Hybrid Retrieval

Global planning operates through a two-stage process. First, the system performs image-node matching using a hybrid retrieval strategy that combines:

  1. Keyframe retrieval: Computing cosine similarity between input image DINOv2 embeddings and stored keyframe embeddings
  2. Object retrieval: Matching detected objects in the input image with stored object embeddings of the same semantic category

The hybrid approach averages keyframe and object similarity scores to select the best matching nodes for both current observation and visual goal. Once nodes are matched, A* search on the SMG generates a node-level trajectory (v1,…,vK−1,vK)(v_1, \ldots, v_{K-1}, v_K)(v1​,…,vK−1​,vK​) where vKv_KvK​ explicitly represents the final visual goal.

Geometry-Enhanced Local Navigation

The local navigation component leverages a pre-trained foundation policy enhanced with geometric reasoning capabilities. The key innovation is the VGGT-adapter, which integrates 3D-aware features from the Visual Geometry Group Transformer into the navigation policy.

The VGGT-adapter extracts feature maps from both observation and goal images, spatially pools and flattens them into token sequences, then projects them through a lightweight MLP into the policy's embedding space. These geometry-enhanced features are concatenated with the policy's original visual tokens, providing improved visual goal alignment and robustness to viewpoint changes.

The enhanced policy operates in two modes:

  • Point-goal mode: For intermediate nodes, using 3D positions as targets
  • Image-goal mode: For final approach, leveraging enhanced visual alignment capabilities

Dual-Frequency Planning Loop

MG-Nav employs an asynchronous dual-frequency control scheme:

  • Slow global loop (frequency TgT_gTg​): Periodically re-localizes the agent on the SMG and re-plans the path using A* search
  • Fast local loop (frequency Tl≪TgT_l \ll T_gTl​≪Tg​): Continuously executes short-horizon actions toward intermediate nodes or the final goal

This architecture minimizes computational overhead while maintaining long-horizon goal intent and adapting to environmental changes.

Results and Performance

MG-Nav demonstrates state-of-the-art performance across challenging visual navigation benchmarks, significantly outperforming existing methods in both accuracy and efficiency.

Benchmark Performance

On the HM3D Instance-Image-Goal benchmark, MG-Nav achieves a Success Rate (SR) of 78.5% and Success Rate weighted by Path Length (SPL) of 59.3%. This substantially surpasses previous state-of-the-art memory-based methods like BSC-Nav (SR 71.4%, SPL 57.2%) and GaussNav (SR 72.5%, SPL 57.8%), while vastly outperforming foundation policies like NavDP (SR 24.7%, SPL 12.6%) and RL methods like CompassNav (SR 35.6%, SPL 14.8%).

For MP3D Image-Goal navigation, MG-Nav attains an SR of 83.77% and SPL of 57.15%, representing significant improvement over the strongest RL baseline FGPrompt-EF (SR 77.71%, SPL 51.09%) and foundation policies like NavDP (SR 15.49%, SPL 7.96%).

Component Analysis

Ablation studies reveal the critical contribution of each component:

  • Using only the foundation policy results in poor performance (SR 24.7%, SPL 12.6%)
  • Adding the SMG dramatically improves performance to SR 74.04%, SPL 56.14%
  • Incorporating the VGGT-adapter further enhances results to SR 78.50%, SPL 59.27%

The hybrid retrieval strategy proves essential, as using only keyframe retrieval (SR 73.52%, SPL 52.90%) or object retrieval (SR 72.20%, SPL 52.79%) leads to substantial performance degradation.

Robustness to Dynamic Changes

A key strength of MG-Nav is its robustness to dynamic scene changes. When random obstacles are inserted after SMG construction, MG-Nav shows only minor performance drops (SR decreases from 73.53% to 68.63% with 10 obstacles). In contrast, mapping-based methods like BSC-Nav suffer dramatic degradation (SR drops from 25.49% to 7.84% with 10 obstacles), demonstrating the brittleness of dense reconstruction approaches.

Significance and Impact

MG-Nav represents a significant advancement in embodied visual navigation, offering several key contributions that address fundamental challenges in the field.

The sparse spatial memory paradigm provides a practical alternative to computationally expensive dense reconstruction methods while maintaining the global reasoning capabilities necessary for long-horizon navigation. This approach significantly reduces memory requirements and computational overhead while improving robustness to environmental changes.

The geometry-enhanced local control demonstrates the importance of integrating 3D-aware features into navigation policies, particularly for visual goal alignment and viewpoint invariance. The VGGT-adapter's lightweight design makes this enhancement practical for real-time deployment.

The dual-scale framework successfully bridges the gap between global planning and local control, enabling effective navigation in complex environments while maintaining adaptability to dynamic conditions. The bio-inspired design provides a compelling paradigm for future embodied AI systems.

The demonstrated robustness to dynamic environments addresses a critical limitation of existing memory-based approaches, making MG-Nav more suitable for real-world deployment where environments are rarely static. This represents a significant step toward practical embodied navigation systems.

The methodology's potential extends beyond visual navigation to other spatial reasoning tasks in embodied AI, including manipulation, exploration, and human-robot interaction. The sparse memory graph concept combined with geometry-enhanced perception offers broad applicability across embodied intelligence applications.
