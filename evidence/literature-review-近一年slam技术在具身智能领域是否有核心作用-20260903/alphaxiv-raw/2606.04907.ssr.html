Abstract

Visual navigation requires generating smooth and collision-free trajectories under complex geometric and physical constraints. Existing reactive policies that directly map observations to actions lack anticipatory reasoning, limiting their ability to proactively avoid obstacles. While visual imagination offers predictive foresight, conventional modular approaches separate scene prediction from policy learning, often leading to error accumulation and inefficient inference. To address these limitations, we propose WAM-Nav, a Latent World-Action Model for embodied visual navigation that jointly learns action generation and latent visual foresight, enabling more robust and foresighted navigation decisions without compromising inference efficiency. Specifically, WAM-Nav utilizes a shared Diffusion Transformer for asymmetric joint diffusion to concurrently generate long-horizon actions and short-horizon visual foresight, reducing the inference latency and visual error accumulation inherent in multi-step autoregressive rollouts. To further encourage smooth and consistent trajectory generation, we introduce a dual-stream contextual conditioning mechanism that integrates episode-level ego-motion history with sequential visual observations. Combined with a unified goal alignment module that preserves balanced representations across goal types, WAM-Nav naturally supports Image-Goal, Point-Goal, and No-Goal exploration within a single policy. Extensive experiments on the challenging ClutterScenes and InternScenes benchmarks demonstrate strong generalization of WAM-Nav, particularly on Image-Goal and Point-Goal navigation, where it improves success rates by 15.7% and 3.3%, respectively. Real-world deployment further validates effective zero-shot sim-to-real transfer, achieving an average 85% task success rate across diverse indoor and outdoor environments.

AI Overview

Understanding Unified Visual Navigation

Embodied visual navigation is the process by which an autonomous agent—such as a mobile robot or a humanoid—navigates through an environment using only visual sensors and goal specifications. Traditionally, this problem has been approached through reactive end-to-end policies that map current observations directly to actions. However, these systems often lack "foresight," meaning they do not explicitly predict the future consequences of their movements, which can lead to collisions in cluttered environments.

Figure 1: (a) Comparison between reactive policies, modular world models, and the joint modeling approach of WAM-Nav. (b) Performance benchmarks across Image-Goal, Point-Goal, and No-Goal navigation tasks.

WAM-Nav introduces an Asymmetric Latent World-Action Modeling framework to bridge the gap between reactive control and predictive reasoning. Unlike modular systems that decouple scene prediction from policy learning—a process often plagued by high latency and error accumulation—WAM-Nav jointly learns action generation and visual foresight within a single, unified architecture. This allows the agent to "imagine" its near-future surroundings while simultaneously planning its path, ensuring that its intended actions are both kinematically feasible and geometrically safe.

Unified Goal Alignment

A significant challenge in visual navigation is the diversity of task specifications. An agent might be asked to reach a location shown in an image (Image-Goal), move toward specific relative coordinates (Point-Goal), or simply explore an unknown area without a fixed target (No-Goal). Most existing methods are specialized for a single modality, requiring separate models for different tasks.

WAM-Nav addresses this via a Unified Goal Alignment (UGA) mechanism. Instead of forcing all goals into a single format, it processes the input goal ggg through a modality-specific encoder Eϕ(g)→egE_\phi(g) \to e_gEϕ​(g)→eg​ and then projects it into two distinct queries:

  1. Visual Semantic Query (gVg_VgV​): This embedding is designed to retrieve relevant features from the agent's visual memory. For instance, if the goal is an image of a red chair, gVg_VgV​ helps the agent focus on "red chair" features in its current and past observations.
  2. Geometric Query (gGg_GgG​): This embedding provides directional guidance. For a point goal, it captures the spatial vector the agent must follow.

By using these dual queries, the model maintains the specialized information needed for different task types while providing a common interface for the downstream generation blocks.

Spatiotemporal Contextualization

For a robot to navigate smoothly, it must understand its history. WAM-Nav uses a Dual-Stream Contextual Conditioning (DSCC) module to integrate two types of history: visual observations and physical motion.

Simultaneously, the motion stream processes the agent's recent trajectory St={st−k+1,…,st}S_t = \{s_{t-k+1}, \dots, s_t\}St​={st−k+1​,…,st​}. This vector ensures the agent maintains "momentum" and generates paths that are physically consistent with its previous movements. The final conditioning context CCC is a fusion of these two streams, providing a comprehensive representation of where the agent is, where it has been, and where it needs to go.

Asymmetric Action-Foresight Generation

The core innovation of WAM-Nav is how it generates the future. It uses a Diffusion Transformer (DiT) to jointly predict a long-horizon action trajectory At={at,…,at+Hact−1}A_t = \{a_t, \dots, a_{t+H_{\text{act}}-1}\}At​={at​,…,at+Hact​−1​} and a short-horizon latent visual foresight sequence Zt+1:t+Hvis={zt+1,…,zt+Hvis}Z_{t+1:t+H_{\text{vis}}} = \{z_{t+1}, \dots, z_{t+H_{\text{vis}}}\}Zt+1:t+Hvis​​={zt+1​,…,zt+Hvis​​}.

Figure 2: The WAM-Nav architecture, featuring Unified Goal Alignment, Dual-Stream Contextual Conditioning, and the Shared Diffusion Transformer for joint action and foresight generation.

The design is specifically "asymmetric" because the action horizon is longer than the visual foresight horizon (Hvis≤HactH_{\text{vis}} \leq H_{\text{act}}Hvis​≤Hact​). In practice, the authors found that Hact=16H_{\text{act}} = 16Hact​=16 steps combined with Hvis=1H_{\text{vis}} = 1Hvis​=1 (predicting just the next frame) provided the best balance.

This asymmetry is a strategic choice for navigation. Unlike robot manipulation, where the camera is often static or moves slowly, navigation involves large changes in viewpoint. Predicting the visual environment many seconds into the future is extremely difficult and prone to "hallucinations" or errors that can accumulate and mislead the agent. By focusing on a very short visual horizon, WAM-Nav provides a reliable geometric constraint—essentially "checking" if the immediate next step is clear of obstacles—while the long action horizon ensures smooth, continuous movement over time.

Both the action noise and latent image noise are fed into the same DiT blocks. Inside these blocks, they share self-attention layers. This allows the model to naturally regularize the action path based on the predicted future scene; if the visual foresight predicts an obstacle, the shared representation forces the action tokens to steer away from it.

Figure 3: The Shared Diffusion Transformer block. Heterogeneous tokens for actions and images undergo shared self-attention, allowing for mutual constraints between the physical path and visual foresight.

Training and Deployment

The model is trained using a flow-matching objective, which is an efficient alternative to standard diffusion training. It learns to map a simple Gaussian distribution to the complex distribution of real-world trajectories and scenes. The total loss function combines the flow-matching error for both actions and images with a contrastive alignment loss:

Ltotal=λfmLfm+λalignLalign(3)\mathcal{L}_{\text{total}} = \lambda_{\text{fm}} \mathcal{L}_{\text{fm}} + \lambda_{\text{align}} \mathcal{L}_{\text{align}} \quad (3)Ltotal​=λfm​Lfm​+λalign​Lalign​(3)

The alignment loss ensures that the visual and geometric queries stay synchronized across different goal types.

For real-world deployment, the robot operates in a "receding horizon" loop. At every time step, it generates 16 potential futures, selects the most likely action trajectory, executes the first part of it, and then repeats the process with new sensor data. This allows the robot to remain responsive to dynamic changes in the environment.

Performance and Real-World Validation

WAM-Nav was tested extensively in both simulations (IsaacSim) and the real world using humanoid robots like the Unitree G1.

Figure 4: Qualitative comparison of WAM-Nav against reactive baselines. WAM-Nav (green) successfully avoids obstacles by anticipating future states, while baselines (red) often collide or get stuck.

In simulations involving thousands of episodes across cluttered and complex home layouts, WAM-Nav significantly outperformed previous state-of-the-art models like NavDP. For example, in Image-Goal tasks, it achieved a Success Rate (SR) of 50.2%, a substantial improvement over the 34.5% seen in reactive models.

Figure 5: Zero-shot deployment on a Unitree G1 humanoid. The model demonstrates robust navigation in diverse settings, including warehouses, lobbies, and parking lots, without any fine-tuning on real-world data.

Perhaps most impressively, the model showed strong zero-shot sim-to-real transfer. Despite being trained entirely on simulated data (the VLN-N1 dataset), it successfully navigated a humanoid robot through real warehouses and parking lots with an 85% success rate. The latent foresight acts as a universal geometric checker that helps the agent adapt to the physics of the real world.

Conclusion

WAM-Nav demonstrates that "imagining" the immediate future is a powerful tool for autonomous navigation. By combining long-term action planning with short-term visual foresight in an asymmetric architecture, it overcomes the reactive limitations of previous policies and the computational slowness of traditional world models. This unified approach provides a blueprint for building more reliable, anticipatory agents capable of handling diverse tasks in complex, real-world environments.
