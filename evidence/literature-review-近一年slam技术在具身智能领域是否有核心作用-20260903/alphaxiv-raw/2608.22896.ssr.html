Abstract

Robotic navigation in human environments requires a spatio-temporal semantic representation that can rec- oncile open-vocabulary perception with long-term environmental changes. While foundation models provide strong zero-shot recognition, their predictions are intermittent and view-dependent, and naively integrating them into mapping pipelines leads to identity drift and stale semantics over time. We present SuperMap, a 4D spatio-temporal mapping framework for language-guided navigation that integrates high-frequency geometric SLAM with asynchronous open-vocabulary perception. Our core contribution is a consistency-driven mapping engine that combines 3D-aware instance association/re-activation with a principled existence-and-label confidence update to maintain stable object identities and prune outdated map content under occlusions and scene changes. SuperMap produces a queryable 4D scene-graph representation that interfaces naturally with Vision-Language Models by supporting compositional queries over object semantics, relations, We demonstrate SuperMap on benchmarks and real robots, including dynamic scenes with appearance/disappearance and relocation, and provide ablations and runtime analysis. We release the full system as open-source to provide the community with a deployable baseline for open-vocabulary spatio-temporal mapping. Project website: this http URL.

AI Overview

Bridging Perception and Reasoning in Dynamic Environments

Robotic navigation in human-centric environments requires a sophisticated understanding of the world that extends beyond simple geometry. While traditional Simultaneous Localization and Mapping (SLAM) systems excel at estimating a robot's pose and reconstructing the physical layout of a space, they often fail to capture the semantic and temporal nuances necessary for high-level interaction. A robot operating in a home or office must not only know where the walls are but also identify specific object instances, understand their relationships, and track how the environment changes over time.

Figure 1: SuperMap maintains an instance-level 4D semantic map, allowing robots to identify when objects appear or disappear and maintain consistent identities despite environmental dynamics.

Existing semantic mapping approaches typically face a trade-off between speed and depth of understanding. Closed-vocabulary systems are fast but limited to a fixed set of object categories, while open-vocabulary methods using foundation models often suffer from "identity drift"—where the same object is inconsistently labeled across different frames—or struggle with "stale semantics" when an object is moved or removed. SuperMap addresses these challenges by introducing a real-time, spatio-temporal SLAM system that constructs a "4D scene memory." This system integrates high-frequency geometric state estimation with asynchronous, open-vocabulary perception to maintain a consistent, queryable representation of the environment.

The SuperMap Architecture

SuperMap organizes its environmental representation into three distinct layers: a Geometric Layer, an Instance Layer, and a Topological Layer. The system processes a continuous stream of RGB-D or point-cloud data to estimate the robot's pose PtP_tPt​ and update the global map MtM_tMt​ at each time step ttt.

The core problem is formulated as maximizing the posterior probability of the robot's trajectory and the environment state:

where P1:tP_{1:t}P1:t​ represents the sequence of poses, I1:tI_{1:t}I1:t​ the instance identities, and O1:tO_{1:t}O1:t​ the sensor observations. This complex estimation is decomposed into three sub-tasks: reliable pose estimation, spatio-temporal instance association, and online map updates.

Geometric Foundation and Online Reconstruction

The Geometric Layer provides the metric foundation for the entire system. SuperMap utilizes SuperOdometry, an IMU-centric LiDAR-visual-inertial estimator, to maintain high-frequency state estimation. This module produces the robot pose Pt∈SE(3)P_t \in SE(3)Pt​∈SE(3) and generates a colorized dense 3D reconstruction.

Having an accurate metric prior is essential for three reasons:

  1. Back-projection: It allows the system to accurately project 2D semantic detections from images into the 3D world coordinate frame.
  2. Motion Compensation: It enables the system to predict where an object should appear in the next camera frame based on the robot's own movement, which is critical for maintaining object identity.
  3. Global Consistency: It ensures that semantic information collected from different viewpoints is correctly fused into a unified global map.

Instance Association and Motion Compensation

The Instance Layer is where SuperMap identifies and tracks individual objects. Unlike traditional trackers that operate purely in the 2D image plane, SuperMap uses a 3D-aware approach to handle aggressive robot maneuvers and occlusions.

For each frame, the system generates 2D instance proposals using models like GroundingDINO and SAM2. To associate these new detections with existing objects in the map, the system maintains a tracklet state Si(t)={ui,vi,wi,hi,u˙i,v˙i}S_i(t) = \{u_i, v_i, w_i, h_i, \dot{u}_i, \dot{v}_i\}Si​(t)={ui​,vi​,wi​,hi​,u˙i​,v˙i​}, where (u,v)(u, v)(u,v) is the image centroid and (w,h)(w, h)(w,h) represents the bounding box dimensions.

Crucially, instead of assuming a linear motion model for objects in the image, SuperMap projects the 3D centroid Xi∈R3X_i \in \mathbb{R}^3Xi​∈R3 of an object from the previous map Mt−1M_{t-1}Mt−1​ into the current 2D frame using the new pose PtP_tPt​. This projection serves as a strong prior for a Kalman Filter, allowing the system to maintain a stable identity for an object even if it is momentarily occluded or if the robot rotates quickly.

Maintaining Map Integrity through Change Detection

Human environments are rarely static. To prevent the map from becoming cluttered with "ghost" objects that have been moved or removed, SuperMap employs a Probabilistic Geometric Consistency Update. For every point in the map, the system calculates a depth residual Δd\Delta dΔd:

Δd=dproj−dsensor\Delta d = d_{proj} - d_{sensor}Δd=dproj​−dsensor​

where dprojd_{proj}dproj​ is the expected depth based on the current map and dsensord_{sensor}dsensor​ is the actual depth measured by the sensor. Points are then classified based on this residual:

  • Observable: The measured depth matches the map.
  • Unobservable: The point is behind a surface in the current view.
  • Disappeared: The sensor sees clear space where a map point used to be (Δd\Delta dΔd is significantly positive).

The occupancy state of the map is updated using a log-odds formulation:

Points that are consistently classified as "disappeared" are penalized in their log-odds score and eventually pruned from the map. This mechanism allows SuperMap to detect environmental changes in real-time, such as a chair being moved to another room.

Bayesian Semantic Fusion

Vision-Language Models (VLMs) can be noisy and intermittent. A single frame might misidentify a "trash can" as a "bucket." SuperMap mitigates this by treating semantic labels probabilistically. Each object instance maintains a categorical distribution Bt(c)=P(c∣O1:t)B_t(c) = P(c | O_{1:t})Bt​(c)=P(c∣O1:t​) representing the belief of its class ccc. As new observations arrive, this belief is updated using a Bayesian fusion approach that considers the detector's confusion matrix. Only objects with a sufficiently high confidence score are retained, which helps filter out transient misclassifications and results in a cleaner semantic map.

The 4D Scene Graph

The Topological Layer abstracts the dense instance map into a queryable graph G=(V,Es,Et)G = (V, E_s, E_t)G=(V,Es​,Et​).

  • Nodes (VVV): Represent individual object instances with their identities, labels, and 3D centroids.
  • Spatial Edges (EsE_sEs​): Represent geometric relations like "On," "Next to," or "Under." These are determined using predicates based on overlap and relative position (e.g., checking the z-axisz \text{-axis}z-axis for "On" relations).
  • Temporal Edges (EtE_tEt​): Link the same instance across different time steps, effectively recording the trajectory and history of every object.

Grounded Reasoning and Navigation

The ultimate utility of the 4D scene graph is its ability to interface with Large Vision-Language Models (LVLMs) for navigation. Rather than providing the VLM with a raw video feed—which is computationally expensive and prone to perspective errors—SuperMap serializes the local scene graph into a structured text format. This text includes instance IDs, labels, and symbolic relationships (e.g., "Instance 5 is on Table 2").

When a user gives a command like "Go to the chair that was near the plant earlier," the system can retrace temporal edges to find the historical location of that specific chair. The VLM processes the graph and returns the target instance ID. A parser then retrieves the 3D coordinates for that ID from the map and generates a navigation waypoint for the robot's path planner.

Quantitative Performance and Real-World Impact

SuperMap was evaluated on the ScanNet benchmark and through real-robot deployments. On ScanNet, it achieved an instance segmentation mAP@50 score for categories like "Chair" (63.76%) and "Refrigerator" (62.50%) that significantly outperformed other open-vocabulary baselines like ConceptGraphs. This superior performance is largely due to the system's ability to track objects in 3D rather than relying on inconsistent 2D clustering.

In real-world experiments involving a 10-minute operation in a dynamic office, the system maintained high recall for both object detection and change detection. While baseline methods often failed to recognize when an object had been removed, SuperMap correctly updated its world model, ensuring the robot did not attempt to navigate toward an object that was no longer there.

Figure 5: SuperMap enables zero-shot navigation in unseen environments, allowing a robot to ground complex instructions like "Go to the whiteboard next to the painting."

The system operates in real-time on standard robotic hardware, with pose estimation at 10 Hz and full 4D scene graph updates at 5 Hz. By providing a deployable, open-source framework for spatio-temporal mapping, SuperMap offers a robust baseline for the next generation of robots capable of long-term autonomy and sophisticated natural language interaction in the ever-changing human world.
