Abstract

Open-vocabulary scene understanding with online panoptic mapping is essential for embodied applications to perceive and interact with environments. However, existing methods are predominantly offline or lack instance-level understanding, limiting their applicability to real-world robotic tasks. In this paper, we propose OnlinePG, a novel and effective system that integrates geometric reconstruction and open-vocabulary perception using 3D Gaussian Splatting in an online setting. Technically, to achieve online panoptic mapping, we employ an efficient local-to-global paradigm with a sliding window. To build local consistency map, we construct a 3D segment clustering graph that jointly leverages geometric and semantic cues, fusing inconsistent segments within sliding window into complete instances. Subsequently, to update the global map, we construct explicit grids with spatial attributes for the local 3D Gaussian map and fuse them into the global map via robust bidirectional bipartite 3D Gaussian instance matching. Finally, we utilize the fused VLM features inside the 3D spatial attribute grids to achieve open-vocabulary scene understanding. Extensive experiments on widely used datasets demonstrate that our method achieves better performance among online approaches, while maintaining real-time efficiency.

AI Overview

The Challenge of Real-Time 3D Scene Understanding

For robots and autonomous agents to effectively operate in human environments, they must understand their surroundings with high precision. This task, known as 3D scene understanding, traditionally involves two main components: geometry (where things are) and semantics (what things are). Historically, semantic mapping was "closed-set," meaning the system could only recognize a fixed list of objects, like "chair," "table," or "wall."

With the rise of Vision-Language Models (VLMs) like CLIP, the field has shifted toward "open-vocabulary" understanding. This allows a system to identify objects based on any natural language query, such as "a red coffee mug" or "a stack of books," even if those categories weren't in the training data. Furthermore, "panoptic" mapping combines semantic understanding (categories) with instance segmentation (distinguishing individual objects of the same category).

However, a major bottleneck remains: most advanced open-vocabulary 3D mapping systems operate "offline." They require a robot to first capture all data, then process it for hours on a powerful server. For a robot to explore a new room and interact with it immediately, it needs an "online" system—one that processes data frame-by-frame and updates its internal map in real-time. OnlinePG addresses this by integrating 3D Gaussian Splatting (3DGS) with a robust local-to-global mapping paradigm.

Core Representation: 3D Gaussian Splatting Meets Semantic Grids

To represent the world, OnlinePG uses 3D Gaussian Splatting, a technique that models the environment as a collection of millions of tiny, semi-transparent 3D "blobs" or Gaussians. Unlike traditional points or voxels, 3DGS allows for extremely fast rendering and high-quality geometric reconstruction. Each Gaussian GiG_iGi​ is defined by its position μi\mu_iμi​, a covariance matrix Σi\Sigma_iΣi​ representing its shape/orientation, an opacity value σi\sigma_iσi​, and a color cic_ici​.

While 3DGS is excellent for geometry and appearance, storing complex language features (which can have hundreds of dimensions) for every single Gaussian is computationally expensive and memory-intensive. To solve this, OnlinePG introduces a hybrid approach: it uses 3DGS for geometry but stores semantic and instance information in a set of sparse, grid-based spatial attribute structures.

For every occupied voxel vvv in the scene, the system maintains:

  • A language feature F∈RDfF \in \mathbb{R}^{D_f}F∈RDf​ (extracted from VLMs).
  • A confidence score C∈RC \in \mathbb{R}C∈R for that feature.
  • A panoptic instance label T∈RT \in \mathbb{R}T∈R.
  • An instance weight K∈RK \in \mathbb{R}K∈R to track the reliability of the label.

This separation allows the system to optimize geometry quickly using the 3DGS pipeline while efficiently updating and querying high-dimensional semantic data through the grid.

Local Consistency: Tackling 2D Noise

A major difficulty in online 3D mapping is the "noise" inherent in 2D predictions. When a robot looks at a chair from one angle, a VLM might identify it perfectly; from another angle, it might only see a "wooden leg" or miss it entirely due to motion blur or lighting. If these inconsistent 2D masks are directly projected into 3D space, the resulting map becomes a fragmented mess of overlapping instances.

OnlinePG manages this using a "local consistent map" strategy. It maintains a sliding window WWW of recent keyframes. Instead of immediately merging every new frame into the global map, it first builds a clean local map within this window.

3D Segment Initialization

For each keyframe, the system extracts 2D semantic features (using LSeg) and instance masks (using EntitySeg). These 2D masks are projected into 3D space to create "3D segments" SiS_iSi​. Because 2D segmentation is often inconsistent, the system ends up with many overlapping or partial segments for the same object.

Multi-Cue Clustering

To group these noisy segments into consistent 3D instances, OnlinePG uses a graph-based clustering algorithm. It calculates the similarity between segments SiS_iSi​ and SjS_jSj​ using three distinct cues:

  1. Geometry Cue O(Si,Sj)O(S_i, S_j)O(Si​,Sj​): Measures how much physical volume the two segments share.
  2. Semantic Cue X(Si,Sj)X(S_i, S_j)X(Si​,Sj​): Measures the cosine similarity between the language features extracted from their respective 2D regions.
  3. View Consensus Cue V(Si,Sj)V(S_i, S_j)V(Si​,Sj​): Checks if the segments are consistently seen across different camera views.

Segments are merged if they meet specific similarity thresholds (λ1\lambda_1λ1​ or λ2\lambda_2λ2​). This process effectively "cleans" the 2D noise, resulting in a set of stable local instances III. Once clustered, the local spatial attribute grids—such as the instance label Tlt(v)T^t_l(v)Tlt​(v) and language feature Flt(v)F^t_l(v)Flt​(v)—are populated using weighted averaging based on observation frequency and confidence.

The Local-to-Global Paradigm: Seamless Mapping

Once a locally consistent map is created, it must be fused into the ever-growing global map. This is where the "Local-to-Global" paradigm comes into play. The system must decide: Is this local chair the same as the chair I saw five minutes ago, or is it a new one?

OnlinePG uses Bidirectional Bipartite Matching to solve this. It creates two matching matrices:

  • Forward Matrix Ml→gM_{l \to g}Ml→g​: Compares local instances to existing global instances based on their language features and spatial overlap.
  • Backward Matrix Mg→lM_{g \to l}Mg→l​: Compares global instances back to the current local view.

By using the Hungarian algorithm and intersecting the results of both matrices, the system finds a set of matches AAA that are bidirectionally consistent. This is much more robust than simple nearest-neighbor matching, which often leads to "drifting" labels where an object's identity changes as the robot moves.

Updating the Global Map

After matching, the global spatial attribute grids are updated. For a voxel vvv:

  • Language Features: The global feature Fgt(v)F^t_g(v)Fgt​(v) is updated via a weighted average with the local feature Flt(v)F^t_l(v)Flt​(v), using their respective confidence scores Cgt(v)C^t_g(v)Cgt​(v) and Clt(v)C^t_l(v)Clt​(v).
  • Instance Labels: If a local instance matches a global one, the global label Tgt(v)T^t_g(v)Tgt​(v) is kept, and its weight Kgt(v)K^t_g(v)Kgt​(v) is increased. If a local instance is much "stronger" (more observations) than an old global label, it can replace it, allowing the system to correct past mistakes.

Results and Performance

OnlinePG was evaluated on standard datasets like ScanNetV2 and Replica, comparing it against both online and offline mapping methods.

Accuracy and Quality

In 3D semantic segmentation, OnlinePG significantly outperformed existing online baselines like OnlineAnySeg, achieving an improvement of roughly 13.8 mIoU on ScanNetV2. This suggests that its fine-grained voxel-level feature grid is much better at preserving semantic details than methods that assign a single averaged feature to an entire 3D object.

In panoptic segmentation (PRQ), it even surpassed some state-of-the-art offline methods. This is noteworthy because offline methods have the advantage of "seeing" the whole scene at once, whereas OnlinePG must make decisions incrementally.

Efficiency

A critical requirement for OnlinePG was real-time performance. On a modern workstation (RTX 4090), the system achieves:

  • 18 FPS in simple scenes.
  • 10 FPS in complex, cluttered scenes.

While the VLM feature extraction (a separate process) adds latency, the core mapping, clustering, and fusion pipeline is fast enough for robotic navigation and interaction.

Open-Vocabulary Queries

Because the system stores high-dimensional language features in a 3D grid, users can query the map with arbitrary text. For example, a user could ask for "the blue pillow" or "the cardboard box," and the system can localize these specific instances by comparing the query's CLIP embedding with the features stored in the grid.

Significance and Future Outlook

The development of OnlinePG represents a shift toward more capable embodied AI. By enabling robots to build panoptic, open-vocabulary maps in real-time, the system allows for:

  1. Dynamic Interaction: A robot can enter a room and immediately find an object described by a human using natural language.
  2. Robust Perception: The system doesn't rely on perfect 2D inputs; its clustering and bidirectional matching allow it to recover from temporary occlusions or poor sensor data.
  3. Fine-Grained Understanding: Distinguishing between different instances of the same category (e.g., "the chair near the door" vs. "the chair near the window") is essential for complex task execution.

While the current system assumes a static environment (it cannot yet track objects moving independently, like a person walking), the local-to-global framework provides a foundation for future research into dynamic online 3D scene understanding. By moving these capabilities from the lab (offline) to the robot (online), OnlinePG bridges a critical gap in the quest for truly autonomous agents.
