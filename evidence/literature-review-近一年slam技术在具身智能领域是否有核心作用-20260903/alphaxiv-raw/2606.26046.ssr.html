Abstract

We present RoboAtlas, a contextual Active SLAM framework that adaptively balances geometric exploration and semantic reasoning using a scalable 3D semantic mapping system, OpenRoboVox. RoboAtlas integrates frontier exploration, global semantic-map reasoning, and egocentric VLM-based reasoning through a contextual multi-armed bandit that transitions from exploration to semantically guided navigation as scene understanding improves. We evaluate the system in simulation and on a Unitree Go2 robot in large-scale real-world environments exceeding 1800 m2 with approx. 30k mapped semantic instances, achieving a 100% task success rate. On the GOAT-Bench "Val Unseen" benchmark, RoboAtlas achieves state-of-the-art performance with highest reported success rate (SR) of 90.6%, using GPT-4o, improving over the strongest prior baseline by 17.8 percentage points in SR. Using the much smaller Qwen2.5-VL-7B model, it still achieves 88.8% SR, outperforming all baselines using GPT-4o in SR, and revealing the importance of the information gained by our semantic mapping framework over simply replacing the underlying foundation model. The results demonstrate that grounding foundation models with large-scale 3D semantic maps enables robust and efficient contextual Active SLAM.

AI Overview

Introduction to Contextual Active SLAM

Autonomous mobile robots must navigate and interact with the physical world, often starting with zero prior knowledge of their surroundings. This capability relies on Simultaneous Localization and Mapping (SLAM), where a robot builds a map while keeping track of its own position. When the robot also makes its own decisions about where to move next to improve that map, the process is called "Active SLAM." Historically, Active SLAM focused on geometric coverage—ensuring the robot "sees" every corner of a room to create a complete floor plan. However, geometric maps are insufficient for high-level tasks like "find the red cart near the printer."

Figure 1: The RoboAtlas framework integrates real-time 3D semantic mapping (OpenRoboVox) with a mixture-of-experts navigation policy coordinated by a Contextual Multi-Armed Bandit (CMAB).

RoboAtlas introduces a framework for "Contextual Active SLAM." It moves beyond simple geometry by integrating instance-level 3D semantic mapping with Large Language Models (LLMs) and Vision-Language Models (VLMs). The core challenge addressed is the trade-off between exploration and exploitation: when should a robot continue exploring new territory (geometric exploration), and when should it use its existing knowledge to hunt for a specific object (semantic exploitation)? RoboAtlas solves this by utilizing a "mixture-of-experts" approach, where a central controller learns to pick the best navigation strategy based on the current context.

OpenRoboVox: Real-Time 3D Semantic Mapping

To perform high-level reasoning, a robot needs more than a point cloud; it needs a structured understanding of objects. RoboAtlas utilizes a mapping system called OpenRoboVox. This system is designed for real-time deployment on physical robots, which often have limited memory and processing power compared to high-end research servers.

OpenRoboVox maintains a large-scale 3D geometric representation using Truncated Signed Distance Fields (TSDF) and a probabilistic voxel grid for semantics. The system continuously distills raw sensor data into a structured semantic memory called the Scene-Dictionary StS_tSt​. Each entry in the dictionary contains crucial metadata:

This structured format allows the robot to "ask" the map questions about the environment. To keep this process efficient, RoboAtlas uses a priority-based scheduler that updates only the most relevant objects (based on how recently they were seen or how consistently they appear). This ensures the update cost is O(1)O(1)O(1) relative to the total map size, preventing the robot's "brain" from slowing down as the map grows larger.

Bridging 3D and 2D Representations

While 3D maps are rich in detail, planning a path across a whole building using raw voxels is computationally expensive. RoboAtlas bridges this gap by projecting 3D information into a "2D Pillar Map." Unlike standard 2D occupancy grids that only show if a space is "empty" or "full," each pillar in this map retains a ranked hierarchy of the top-K dominant object instances found at that location.

From this representation, the system generates "Similarity Potential Fields." These fields are heatmaps that represent how well different parts of the environment match the user's request. Three specific fields are used:

  1. Target Similarity (TsimT_{sim}Tsim​): How likely a region contains the target object.
  2. Neighbor Similarity (NsimN_{sim}Nsim​): How likely a region contains objects typically found near the target (e.g., a "mouse" near a "keyboard").
  3. Constraint Similarity (CsimC_{sim}Csim​): Highlighting regions the robot should avoid, such as fragile items or hazardous areas.

These heatmaps provide a mathematical foundation for the navigation experts to make informed decisions about where to go.

The Mixture-of-Experts Navigation Framework

RoboAtlas does not rely on a single navigation algorithm. Instead, it uses a set of "experts" A\mathcal{A}A, each specializing in a different aspect of the mission:

Frontier Exploration Expert (EFrontierE_{\text{Frontier}}EFrontier​)

This expert focuses on the "unknown." It identifies "frontiers"—the boundaries between explored and unexplored space—and selects goals that maximize new map coverage. This is essential in the early stages of a mission when the robot has not yet seen enough of the environment to find the target.

Semantic Map Expert (ESemanticMapE_{\text{SemanticMap}}ESemanticMap​)

This expert performs global reasoning over the entire Scene-Dictionary StS_tSt​. It uses an LLM to analyze the metadata of all discovered objects. For example, if the task is to find a "coffee mug," and the dictionary lists a "table" and a "bookshelf," the LLM will likely prioritize the table as a candidate location based on common-sense spatial relationships.

Egocentric VLM Expert (EEgoVLME_{\text{EgoVLM}}EEgoVLM​)

This expert looks at the robot's immediate "egocentric" view—the current image from its camera. It uses a VLM to determine if the target is visible or if a simple corrective action (like turning 45∘45^{\circ}45∘ to the left) is needed. This provides fine-grained, local control that complements the global view of the semantic map expert.

By learning which expert provides the highest reward in different contexts, the robot develops a sophisticated policy. In a brand-new room, the reward for exploration is high, so it favors the Frontier expert. Once it spots something relevant, the reward for semantic exploitation increases, and it switches to the Semantic Map or Egocentric VLM experts to close in on the goal.

Experimental Evaluation and Findings

The researchers validated RoboAtlas through extensive testing in simulation and on a physical Unitree Go2 quadruped robot.

Large-Scale Mapping Performance

In real-world tests, OpenRoboVox mapped over 180018001800 m2\text{m}^2m2 of an office building, identifying nearly 30,00030,00030,000 unique object instances. The memory-optimized design allowed it to maintain a 15 Hz geometric update rate even on hardware with limited GPU VRAM.

Figure 4: A large-scale semantic map of a multi-floor office environment generated in real-time by OpenRoboVox.

Success on GOAT-Bench

The framework was evaluated on GOAT-Bench, a standard benchmark for multi-modal navigation. RoboAtlas achieved a 90.6%90.6\%90.6% success rate (SR), significantly outperforming previous methods like HIMM (72.8%72.8\%72.8%) and 3D-Mem (68.9%68.9\%68.9%). Notably, the system performed exceptionally well even when using a smaller, more efficient foundation model (Qwen2.5-VL-7B), suggesting that the "mixture-of-experts" architecture is as important as the intelligence of the underlying models.

Expert Allocation Analysis

The study analyzed how often each expert was used. The Egocentric VLM was the most frequent choice (45.0%45.0\%45.0%), serving as a constant local "corrector." The Semantic Map expert was chosen 38.7%38.7\%38.7% of the time but was responsible for almost half of the total distance traveled, proving it is the primary driver for long-range navigation toward known targets. The Frontier expert was used less often (16.4%16.4\%16.4%) but was critical during the initial phases of every mission.

Significance and Future Impact

RoboAtlas demonstrates that autonomous robots can achieve complex, language-guided goals by intelligently balancing "where they haven't been" with "what they already know." By providing a memory-efficient 3D mapping solution and a flexible decision-making framework, this work makes it practical to deploy sophisticated AI reasoning on physical, mobile platforms.

The significance of this work lies in its resilience. Most current semantic navigation systems fail if their map is incomplete or if their object detector makes a mistake. Because RoboAtlas can always fall back on geometric exploration or switch between different types of semantic reasoning, it maintains high performance in the messy, unpredictable environments of the real world. This architecture paves the way for more capable service robots in homes, offices, and industrial settings.
