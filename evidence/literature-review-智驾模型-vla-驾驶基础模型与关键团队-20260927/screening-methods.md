# 检索、筛选与覆盖边界

日期窗口为 2024-09-27—2026-09-27；7 篇窗口前经典前序用于解释技术接口与评测来源。使用 arXiv API 关键词/同义词检索、原始项目网站检索与 Semantic Scholar 引文扩展。冻结的 scoping 最低要求为 100 个候选、35 个完整非 OCR 全文、15 篇正式论文证据；未为适配结果降低阈值。

10 批检索合并得到 1,672 个去重发现项。它是包含宽泛命中的发现池，**不是 1,672 篇均已完成人工摘要筛选**。围绕语言理解/决策、动作生成、分层系统、训练期语言、非语言策略及评测反例作目的性抽样；恢复 39 篇完整全文，深读并接纳 20 篇，其他 19 篇只处于全文恢复层，不进入科学结论。此流程不声称系统综述式全量筛除或穷尽整个领域。

39 篇均为可解析 HTML 完整正文，不使用 OCR。深读包括问题、设计、关键实验/消融、限制及所需附录；不声称逐项复核全部参考文献。20 篇笔记和 46 条主张有原文定位、原文上下文和语义审查说明。论文全文层、深读层、正式证据层在 reading-ledger.jsonl 中分别记录。

核心 8 篇按机制贡献、路线代表性、证据可解释性及后继接口选择：DriveVLM（分层系统）、EMMA（共享文本接口）、ORION（语义规划 token）、SimLingo（语言动作对齐）、AutoVLA（统一动作词表）、Alpamayo-R1（推理与连续动作专家）、Orion-Lite（教师压缩）、DiffusionDrive（非语言动作分布对照）。核心不等同于性能排名；经典评测论文与工业案例仍为阅读主线的必要组成。
