# Source Entry Draft: 近一年触觉在具身机器人领域的发展

## RUN-TACTILE-YEAR-20260720

- 文件：[evidence.jsonl](evidence.jsonl)
- 类型：paper-reader-backed scoping literature review
- 时间标记：paper window 2025-07-20..2026-07-20; reviewed 2026-07-20
- 可信等级：primary synthesis over validated paper-level evidence
- 主题范围：
  - EA-SENSOR：触觉数据、全手表征、视觉—触觉对齐、滑移/接触状态、跨传感器边界。
  - EA-DATA：同步视觉—触觉—动作序列、力/力矩、软物体多视角与恢复数据。
  - EA-MODEL：触觉 VLA、世界动作模型、推理期动作验证、高频残差纠正和全身控制。
  - EA-EVAL：安全过程、滑移/掉落/形变、动作忠实度、闭环与部署边界。
- 证据规模：867 candidates / 124 readable full texts / 23 accepted papers / 24 events。
- 适用：需要复核近一年具身机器人触觉的主要技术转向、代表论文、限制或项目设计含义时读取；论文级定位进入 `paper-note-index.json` 和 `claim-support-audit-index.json`。
- 限制：本轮 arXiv API 增量检索遭遇持续 429，候选覆盖主要复用已结算的 2026-01-14..2026-07-14 多轮触觉 registry，并以 Browser 校准补齐最新与部署维度；TacO 与 TactiDex 完整全文恢复未通过非 OCR 网关，因此未进入正式证据。
