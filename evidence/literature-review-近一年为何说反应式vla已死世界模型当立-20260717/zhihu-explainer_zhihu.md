# VLA 真的已死吗？近一年的论文其实在淘汰“不想后果就动手的机器人”

## TL;DR

VLA 没死，“看一眼画面，读一句指令，直接吐下一段动作”的反应式 VLA 正在过时。近一年的前沿不是把语言、视觉和动作丢掉，而是在它们之间加入一个“先演练后果”的世界模型。

但也别反过来迷信世界模型：能生成逼真视频，不等于能预测滑移、接触、摩擦和真实失败。最可能胜出的是 VLA + 世界模型 + 本体控制的混合系统。

## 误区从哪来：为什么“VLA 已死”听起来很合理？

想象一个机器人在往杯子里倒水。人不是看到杯子就立刻输出一长串手臂坐标。我们会不断检查：杯口在哪，水面是否上升，杯子是否在滑，倾斜再多一点会不会溢出。

经典的反应式 VLA 更像一个背过很多视频的驾驶员：它能从当前画面猜出“此时大概应该左转”，却不一定有一个可查询的内部沙盘，用来比较左转、减速或刹车各自会导致什么。任务越长、接触越多、环境越偏离训练集，这个差别越致命。

## 第一个问题：动作不是一种通用语言

文字 token 的“红色”在不同模型里大体指向同一概念，机器人动作 token 不是这样。[SPACE](https://arxiv.org/abs/2606.24049) 指出，同一控制命令在不同本体、控制器和硬件上可能产生不同运动。[SA-VLA](https://arxiv.org/abs/2606.30113) 也把瓶颈定位在“离散 token 怎么重新变成当下这台机器人的连续控制”。

这就像把“轻轻拿起”同时发给人手、钳子、吸盘和灵巧手。高层意图可以共享，但接触面、力、速度和关节轨迹绝不能照抄。因此，一个真正的通用系统不会只是“把所有动作变成 token”，它还需要共享的世界状态变化和每台机器人专属的动作适配器。

## 第二个问题：基准可能奖励“记住”，不是“理解”

如果训练和测试中的桌面布局、指令逻辑和动作套路很接近，模型可以靠记忆获得一个好看的成功率。[LIBERO-PRO](https://arxiv.org/abs/2510.03827) 说明，LIBERO 的标准协议会过度高估 VLA 泛化。更直观的是 [EgoVLA](https://arxiv.org/abs/2507.12440)：人类第一视角视频能给出庞大的行为先验，但没有机器人微调时，其仿真 humanoid 任务成功率是 0%。

这个结果不是说人类视频无用，而是说“看懂人在做什么”与“让目标机器人做成”之间，隔着动作恢复、坐标对齐、本体转换和真实闭环验证。

## 真实机制：世界模型到底补了什么？

最简单的回答是：它给机器人一个“行动前试想”的接口。

[$\tau_0$-WM](https://arxiv.org/abs/2606.01027) 不只学动作，还联合学习视频未来；它把真实机器人遥操、UMI 式交互、人类第一视角视频以及 rollout/失败轨迹放进同一训练架构。[GEM-4D](https://arxiv.org/abs/2605.22882) 为视频世界模型注入几何特征，让它不只生成像样的像素，还更关心物体在三维空间怎么动。[TACO](https://arxiv.org/abs/2607.02840) 更有意思：它联合预测未来画面和力序列，再用失败附近的想象纠正片段去后训练 VLA。

你会发现，这根本不是“世界模型杀死 VLA”，而是世界模型开始成为 VLA 的动态教师、评委和纠错器。

## 边界：“会做梦”不等于“懂物理”

视频世界模型最容易被误解的地方，就是把“看起来顺”当作“动作后果对”。机器人将夹爪向左移动，生成视频却让物体向右滑；像素仍可能流畅，但这样的模型不能用来规划。

[MiraBench](https://arxiv.org/abs/2605.29360) 因此主张看动作跟随忠实度、物理约束和失败乐观偏差，而不只看视觉质量。[SANTS](https://arxiv.org/abs/2605.27947) 则说得更直白：世界模型的训练和后训练目标应该绑定下游动作质量，后期去噪可能让视频更精致，却更不适合决策。

还有一个无法绕过的现实：视觉并不能看见一切。插入、旋拧、柔性物和滑移任务需要力、触觉或深度补上不可观测状态。[Dream-Tac](https://arxiv.org/abs/2606.08737) 联合学习动作、未来视觉与未来触觉，正是对“视频未来已经足够”的否定。

## 所以，研究路线应该怎么改？

如果你正在做机器人基础模型，可以把投入从“再扩大一个只会预测动作的 VLA”转向四件更难、也更值钱的事：

1. 让数据包含动作后果，而不只是专家动作。
2. 保留 approach、contact、grasp、release 等关键瞬间，不要被普通抽帧洗掉（[SKIP](https://arxiv.org/abs/2606.00664)）。
3. 主动收集失败附近、人工干预和恢复轨迹，而不是只留“漂亮的成功数据”。
4. 用动作忠实、失败乐观偏差、真实闭环成功和恢复率验收世界模型，不要只用 FVD 或主观视频质量。

## 结论

“VLA 已死”是一个有用的当头棒喝，但不是严格的技术结论。更准确的说法是：只会从当前观测模仿下一步、不能比较后果、不知道何时会失败的 VLA，已经不再是通向通用机器人的完整路线。

世界模型“当立”，不是因为它能做更美的梦，而是因为机器人需要在动手之前，先对不同动作可能造成的世界负责。

- [SPACE](https://arxiv.org/abs/2606.24049)：理解为什么跨机器人动作不是可直接混合的通用标签。
- [$\tau_0$-WM](https://arxiv.org/abs/2606.01027)：看统一视频—动作世界模型如何利用异构数据。

- [GEM-4D](https://arxiv.org/abs/2605.22882)：看几何监督如何让视频世界模型更服务于操作。
- [TACO](https://arxiv.org/abs/2607.02840)：一个最直观的“世界模型不是替代 VLA，而是纠正 VLA”的例子。
- [SANTS](https://arxiv.org/abs/2605.27947)：理解为什么世界模型必须以动作质量而非视频保真度验收。
- [Dream-Tac](https://arxiv.org/abs/2606.08737)：理解触觉为什么是接触世界模型不可或缺的补充。
