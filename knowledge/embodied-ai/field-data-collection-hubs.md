# 现场采集 Hub 与物流分拣考察

## Agent Load Hints

- Usually pair with: EA-DATA, EA-BIZ, EA-SENSOR, ERR-PATTERN.
- Raw source needed when: 需要完整现场执行 SOP、口播模板、表格字段、岗位拍摄细则或评分表权重。

## 30 秒摘要

现场采集 Hub 的价值不是“拍到很多视频”，而是形成可复原流程、可定义 episode、可判断 L0/L1/L2/L3 数据方案的证据包。物流分拣场景适合优先考察，因为包裹流向清晰、动作重复、异常真实存在，且系统数据可能与视频对齐。当地人员负责采集真实连续事实，远程机器人数据团队负责判断 Hub 是否适合长期采集、哪些岗位进入试采、以及每个岗位需要什么设备、标注和验收边界。

## 关键判断

- 一次标准考察必须覆盖完整包裹流向、人工岗位盘点、重点岗位视频、访谈、尺寸测量和当天交付清单。
- 重点岗位素材要能回答输入是什么、输出是什么、成功标准是什么、失败如何恢复、系统数据如何对应。
- 每个重点岗位至少需要全景、连续作业、手部/工具特写、物品特写、失败/异常、尺寸/空间六类视频。
- Hub 价值同时取决于机器人替代价值和数据可采性；高痛点但无法连续采集、无法脱敏或安全不可控的现场不适合作首批 Hub。
- 岗位优先级应从动作重复性、感知难度、空间结构化、对象可操作性、人力痛点、L1 示教和 L3 试点可行性共同评分。
- 现场素材验收的关键是远程团队能否定义完整 episode，并确定后续 1-2 周试采岗位和班次。

## 物流岗位与证据需求

| 编号 | 岗位 | 常见动作 | 重点证据 |
|---|---|---|---|
| P01 | 卸车/卸笼/拆袋 | 拿、拖、抛、搬、拆 | 重量、堆叠、破损、弯腰和安全风险 |
| P02 | 供包/上包/单件化 | 抓取、翻面、分开、拉间距、上带 | 连续循环、卡包、滚落、包裹姿态变化 |
| P03 | 扫码/补扫/称重量方 | 找码、扫码、读屏、贴标、分流 | 码面可见性、系统反馈、失败去向 |
| P04 | 格口分拣/投放 | 识别目的地、拿取、投放、塞入 | 目标判断、格口满处理、投放空间 |
| P05 | 装袋/集包/封袋 | 撑袋、装袋、封口、贴标、转运 | 袋满判断、软物形变、封口工具 |
| P06 | 码垛/装车/笼车装载 | 搬运、排序、码放、调整 | 码放规则、狭窄空间、防倒塌 |
| P07 | 异常件处理 | 判断、登记、贴标、转运、重新上线 | 异常类型、恢复策略、系统记录 |
| P08 | 空容器回收/补料 | 收集、折叠、搬运、补充 | 容器尺寸、路径、人流车流干扰 |

## 指标与检核

| 关注点 | 可用指标 |
|---|---|
| 远程复原 | 是否能复原完整流程、岗位位置、输入输出、成功/失败和去向 |
| 视频合格 | 每重点岗位是否具备六类视频、连续循环数、手部/目标同框、尺寸参照物 |
| Hub 条件 | 任务重复性、任务多样性、数据可采性、视觉/空间/安全条件、组织配合度 |
| 岗位优先级 | 动作重复性、人力痛点、感知难度、对象可操作性、L1 示教和 L3 试点可行性 |
| 系统数据 | 条码、格口、称重、量方、异常、班次产能是否能导出并与视频对齐 |
| 合规 | 面单、电话、地址、工牌、系统屏幕和客户信息是否可脱敏和授权 |

## 适用边界

- 适合物流、仓储、分拣、包装、装袋、搬运、异常处理等流程清晰且重复的现场。
- 适合目标机器人尚未确定、但需要先筛 Hub、筛岗位、设计试采和数据方案的阶段。
- 不适合现场安全风险不可控、无法连续采集、任务极不稳定、流程和系统数据无法对应的场景。
- 现场视频可支撑 L0 任务语义和 L1/L2/L3 设计，但不能直接等价为可部署机器人策略数据。
