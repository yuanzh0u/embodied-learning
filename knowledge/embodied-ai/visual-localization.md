# 图像视觉定位

## Agent Load Hints

- Usually pair with: EA-SENSOR, EA-EVAL, EA-HARDWARE, EA-4D.
- Raw source needed when: 需要具体位姿数值、数据集结果、威胁模型或逐句限制。
- Evidence route: 先读 [文献综述成果目录](../literature-review-catalog.md) 的 LR-VLOC，再从 `paper-note-index.json` 选择检索、地图、可靠性或评测论文。

## 30 秒摘要

视觉定位正从单纯提高地点检索召回，转向联合设计地图表示、几何可恢复性、不确定性和评测协议。3DGS、SCR 重建先验、基础模型特征和多参考压缩能降低地图准备成本或增强跨条件能力，但不能消除相关参考选择、唯一几何对应、初值吸引域和分布覆盖的限制。部署时必须把候选召回、几何验证、位姿误差、风险—覆盖、地图成本与隐私攻击面分账。

## 关键判断

- “认出地点”只是定位前端；高 Recall@K 不保证二维—三维对应、PnP 或位姿细化成功。
- 3DGS 的照片真实度不等于几何可定位性；冗余高斯和多对一像素—高斯关系可能破坏对应唯一性。
- 3DGS 位姿细化通常是局部优化，高度依赖检索初值和局部几何质量，不能视为全局纠错器。
- 前馈组合地图和重建先验降低逐场景训练或查询成本，但分别依赖相关参考召回和先验的场景分布。
- 视觉、共视几何和深度先验的融合能缓解感知别名；骨干选择仍受实时预算和困难场景类型约束。
- 多参考地点压缩只有在参考变化覆盖查询变化时可靠；极端新视角可能需要保留原始参考。
- 定位安全必须同时报告错误风险与接受覆盖；全局拒识可以低风险但零效用。
- 固定地理半径真值可能忽略视觉重叠并高估 VPR，尤其在高度或地形变化显著的场景。
- 地理样本频次长尾不能完全代表视觉难度，还需纳入重复纹理、遮挡、季节和标签质量。
- SCR 或神经场的隐式地图不天然保护隐私，风险取决于权重、返回接口和查询权限。

## 指标与检核

| 层级 | 建议指标 |
|---|---|
| 候选检索 | 分条件 Recall@K、尾部地点召回、运行时间 |
| 几何验证 | 图像重叠、对应内点率、PnP 成功率、感知别名率 |
| 位姿估计 | 平移/旋转误差、初始化敏感性、可恢复域、失败分布 |
| 可靠性 | 风险—覆盖曲线、校准误差、拒识率、连续失定位时长 |
| 地图生命周期 | 构建时间、存储、更新延迟、多参考压缩率、地图老化 |
| 隐私安全 | 威胁模型、接口暴露、代理查询预算、几何/外观重建质量 |

## 适用边界

- 现有证据以已知静态场景、路线复访和标准室内外基准为主，不能直接外推到开放世界长期自主运行。
- VPR 检索结论不能直接当作最终六自由度位姿结论；需核验下游几何阶段。
- 深度蒸馏、重建先验和多参考压缩都依赖目标域覆盖，新环境可能需要重新校准或更新地图。
- 允许拒识的安全保证不适用于必须持续输出位置、且没有备用传感器或恢复策略的系统。
- 只返回最终位姿并具有访问控制的服务，其隐私风险不能由暴露稠密场景坐标的攻击实验直接推定。
